# حادثٌ غيّر حياة أسرة — حملة للمساهمة في سداد الدية

نسخة مستقلة من محرّر ملصق التبرعات تعرض قصة الحادث في الصين ومبلغ الدية وشعار اتحاد طلاب اليمن في الصين.

أدخل إجمالي التبرعات في كل قناة باليوان. يتحدّث المبلغ الإجمالي وشريط التقدّم ومعاينة الملصق مباشرةً. يحسب الموقع التعهدات ضمن إجمالي الدعم ويعرضها بجانب المبالغ المستلمة. اترك خانة البنك فارغة أو أدخل شرطة إذا كان مبلغ التحويلات غير متاح.

اضغط **تنزيل صورة PNG** للحصول على الملصق بعرض 2880 بكسل. يتكيّف ارتفاع الصورة مع طول نص النداء. يحفظ المتصفح التعديلات محليًا. يعيد زر **استعادة الملصق الأصلي** المبالغ وصور الرموز وأسماءها وبيانات البنك والنصوص الأصلية دفعة واحدة. تُحفظ الاستعادة في متصفحك أيضًا.

## تعديل بيانات الدفع والنصوص

من قسم **رموز QR والحساب البنكي** يمكنك رفع صورة لكل رمز وتعديل الاسم الذي يظهر تحته وعناوين المجموعات، ورقم الحساب واسم صاحبه. استخدم صورة واضحة بصيغة PNG أو JPG أو WebP، واترك حول الرمز هامشًا أبيض. يتيح قسم **نصوص الملصق** تعديل العنوان والنداء والاقتباس وعبارات الملصق. تظهر التغييرات في المعاينة والصورة المنزّلة.

## نشر التعديلات لجميع الزوار

1. عدّل المبالغ أو بيانات الدفع أو النصوص، ثم افتح قسم **كيف أنشر التعديلات لجميع الزوار؟**.
2. اضغط **تنزيل ملف الإعدادات للنشر**. يضم الملف صور الرموز المستبدلة مع بقية الإعدادات.
3. في مستودع GitHub، استخدم **Add file → Upload files** لرفع ملف `campaign.js` إلى جذر المستودع وحفظ التغيير على فرع `main`. تأكد أن اسم الملف هو `campaign.js` عند رفعه.
4. بعد نشر التحديث من GitHub Pages، تظهر الأرقام الجديدة في الرابط نفسه.

يمكنك أيضًا تعديل `campaign.js` مباشرةً من GitHub. القيم كلها باليوان. القيمة `null` مخصصة لخانة البنك عندما يكون المبلغ غير متاح.

## تشغيل نسخة محلية

من داخل مجلد الموقع شغّل `python -m http.server 8000` ثم افتح [النسخة المحلية](http://localhost:8000/). فعّل GitHub Pages من **Settings → Pages** واختر **Deploy from a branch** ثم `main` و`/(root)`.
